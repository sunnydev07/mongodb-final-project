📋Project Overview

This laboratory project is a complete, practical implementation and benchmarking suite for MongoDB Indexing Strategies. It demonstrates how indexes transform query performance from COLLSCAN (Collection Scan — O(N)) to IXSCAN (Index Scan — O(log N)) across 5,000 synthetic e-commerce records.

The pipeline generates realistic product data across 10 categories and 10 brands, with nested seller info, GeoJSON coordinates, tag arrays, sparse emails, and discount fields — then measures execution statistics (executionStats) before and after indexing.

⚙️Index Types Covered

1. Simple (Single Field)

scripts/02_simple_index.js

Index on a single scalar field (price).

db.products.createIndex({ price: 1 });
5,000 → 2,323 docs examined (53.5% skipped)

2. Compound Index

scripts/03_compound_index.js

Index on category (asc) + price (desc), following the ESR rule.

db.products.createIndex({ category: 1, price: -1 });
95.2% reduction (5,000 → 240 docs)

3. Multikey Index

scripts/04_multikey_index.js

Automatic index on array field tags; one entry per array element.

db.products.createIndex({ tags: 1 });
Direct array lookup without $unwind

4. Text Index

scripts/05_text_index.js

Full-text tokenization, stemming, and stop-word filtering on description.

db.products.createIndex({ description: "text" });
5,000 → 500 docs (TEXT_MATCH stage)

5. Hashed Index

scripts/06_hashed_index.js

MD5 64-bit hash on productId; even shard distribution.

db.products.createIndex({ productId: "hashed" });
1 key + 1 doc examined out of 5,000 (100% precision)

6. Geospatial (2dsphere)

scripts/07_geospatial_index.js

Spherical geometry queries on GeoJSON Point coordinates.

db.products.createIndex({ location: "2dsphere" });
GEO_NEAR_2DSPHERE stage with $maxDistance

7. Unique & Sparse

scripts/08_unique_sparse_index.js

Unique email constraint; sparse index skips documents missing the field.

db.products.createIndex({ email: 1 }, { unique: true, sparse: true });
Prevents duplicate null collisions

8. Partial Index

scripts/09_partial_index.js

Indexes only documents matching partialFilterExpression; saves RAM/disk.

createIndex({ price: 1 }, { partialFilterExpression: { isActive: true } });
5,000 → 1,850 docs examined

9. Wildcard Index

scripts/10_wildcard_index.js

Dynamically indexes arbitrary/polymorphic fields using "$**".

db.products.createIndex({ "$**": 1 });
5,000 → 500 docs examined

Key Takeaways:

  • Compound Index: 95.2% reduction — the single biggest win, returning 240 target records without wasted reads.
  • Hashed Index: Instant O(1) equality resolution — 1 key and 1 document out of 5,000.
  • Geospatial & Text: Enable search stages (GEO_NEAR_2DSPHERE, TEXT_MATCH) that are impractical with plain collection scans.
